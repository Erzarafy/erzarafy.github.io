# Portofolio Erza Al-Isyrafy

Portofolio karya di bidang web development, video editing, dan 3D art. Situs ini dibuat responsif menggunakan HTML, CSS, dan JavaScript tanpa proses build atau dependensi tambahan.

## Menjalankan secara lokal

Buka `index.html` di browser atau jalankan folder ini menggunakan server web statis. Tidak diperlukan instalasi paket maupun proses build.

## Publikasi dengan GitHub Pages

1. Unggah seluruh isi folder ini ke direktori utama repositori GitHub, lalu push ke branch `main`.
2. Buka **Settings → Pages** pada repositori dan pilih **GitHub Actions** sebagai sumber build dan deployment.
3. Workflow `.github/workflows/pages.yml` akan menerbitkan situs setiap kali ada push ke `main`. URL situs tersedia pada hasil workflow dan halaman **Settings → Pages**.

## Formulir kontak
